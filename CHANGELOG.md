What changed in each release, generated by [git-cliff](https://git-cliff.org)

## [2.8.0] - 2026-10-09

### Features

- *(step)* [**breaking**] OpenCASCADE reads and meshes STEP, a part per core, no more fins
- *(step)* Solids stream in as tessellated, the viewer shows them as they come

### Bug fixes

- *(step)* A pool per worker and a coarse retry, so every solid of a big assembly loads
- *(mime)* .obj is a model, not a TGIF drawing, on Debian 12 too
- *(mime)* Define ply, pts, off and step, which only f3d or newer distros did
- *(thumb)* Always write PNG, whatever the output is called
- *(desktop)* The thumbnailer entry runs the tridi on PATH

### Documentation

- Thumbnails beyond Nautilus, and each file manager's size limit

### Build and CI

- *(aur)* 2.7.0

## [2.6.0] - 2026-10-08

### Features

- App id io.github.rccnroll.tridi, AppStream metainfo

### Refactoring

- Library and binary, one concept per module
- Typed errors in the library, eyre with context in the binary
- A strict lint policy: no panics or silent casts left
- Logs through tracing, the user's output through a writer
- Fold banners and one section order in every file

### Documentation

- SECURITY.md, private reporting
- The history leaves the roadmap

- The file map moves to CONTRIBUTING

### Build and CI

- *(deps)* Bump libc to 0.2.190

- *(share)* Drop the Papirus app icon copies
- Keep docs and fuzz out of the crate
- *(package)* Ship the licenses of egui's fonts
